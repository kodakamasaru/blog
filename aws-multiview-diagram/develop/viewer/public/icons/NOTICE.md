# アイコンについて

このディレクトリの SVG は [AWS Architecture Icons](https://aws.amazon.com/architecture/icons/)（2026年1月30日版）です。
npm パッケージ [aws-icons](https://www.npmjs.com/package/aws-icons) に収録されたものを、ファイル名を短くしてコピーしています（Cytoscape で正しい大きさに描画させるため、`viewBox` と同じ `width` / `height` 属性だけ追加しています）。

AWS Architecture Icons の利用条件は AWS の上記ページに従います。
